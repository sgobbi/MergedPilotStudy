## VR Theater Rehearsal Pilot Study

### Description

This project is a Unity-based VR application designed for a pilot study on theater rehearsal in virtual reality. It allows users to explore and manipulate virtual theater scenes while enabling researchers to collect and analyze behavioral and eye-tracking data.

The project includes 6 scenes:

 - 3 fixed (imposed) scenes – Users experience predefined theater environments.

 - 3 interactive scenes – The same scenes, enhanced with a VR menu attached to the user’s left hand for dynamic customization.

Interactive Scene Features (User)

In interactive scenes, the dropdown menu allows users to:

 - Adjust room size – scale the theater environment.

 - Modify lighting – change lighting setups.

 - Manage objects – select from a catalog to:

 - Place objects

 - Interact and position them correctly

 - Delete objects if needed

### Editor Tool Features (Researcher)

The project also includes a dropdown tool menu in the Unity Editor to assist researchers running the user study. Features include:

Scene sequence management – control the order in which participants experience scenes.

Data management – handle save files recording:

User movements

Eye-tracking positions

Data export – streamline collection for later analysis.

This ensures that the pilot study can be conducted efficiently while preserving all experimental data.
